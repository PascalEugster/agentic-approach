# Playbooks

Concrete, step-by-step runbooks for specific situations. The difference from patterns and workflows: patterns describe the shape, workflows describe the process, playbooks tell you exactly what to run.

## The rule

> *Write a playbook the second time you do something, not the first. First time is exploration; second time is where the pattern becomes visible.*
