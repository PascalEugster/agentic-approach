# Workflows

Where patterns and primitives come together into repeatable processes. A workflow is "the thing I actually do when I sit down to ship a feature," not a theoretical shape.

## Index

- [**GSD**](gsd.md) — My default. Phase-based discuss → plan → execute → verify with artifacts on disk.
- [**Worktrees**](worktrees.md) — Parallel isolation for features, experiments, and sub-agent runs.
- [**When to use what**](when-to-use-what.md) — Quick decision table for workflow shape vs. task size.

## The rule

> *Don't use a heavier workflow than the task needs, and don't use a lighter one than it deserves.*

Using GSD for a typo fix is ceremony theater. One-shotting a multi-day feature is debt accumulation. The skill is knowing which is which before you start.
